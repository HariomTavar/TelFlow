# TelFlow

Premium frontend for a **Telecom Service Activation Control Center**.

TelFlow coordinates activation across Inventory, Network, Billing, and Notification so every order ends **ACTIVE** or **ROLLED_BACK** — never partial.

## Stack

React + Vite + TypeScript, Tailwind CSS, Framer Motion, Recharts, Lucide, React Router.

Mock data only. No backend.

## Scripts

```bash
npm install
npm run dev
npm run build
```

Open `http://localhost:5173`.
